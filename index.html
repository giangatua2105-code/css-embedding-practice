Bài tập nhúng CSS vào trang HTML

Phần 1: Inline-style

Đoạn văn này được tô màu bằng inline-style (viết trực tiếp trong thẻ HTML).

Phần 2: Internal-style

Đoạn văn này được tô màu bằng internal-style (viết trong thẻ <style> ở phần <head>).

Phần 3: External-style

Đoạn văn này được tô màu bằng external-style (viết trong file CSS riêng biệt).
